# Aceternity UI — Guia de uso

Fonte: https://ui.aceternity.com

## Papel dentro da Skill

Utilizar principalmente para composição de páginas e seções completas.

## Priorizar para

- landing pages;
- Hero Sections;
- Features;
- Benefits;
- Testimonials;
- Pricing;
- CTA;
- grids;
- cards;
- backgrounds;
- navegação;
- layouts de marketing;
- seções com animações integradas.

## Fluxo recomendado

Para landing pages, verificar primeiro se existe uma estrutura adequada no Aceternity UI antes de construir a seção do zero.

## Adaptação

Extrair estrutura, hierarquia e ritmo visual. Adaptar cores, tipografia, spacing, radius, containers, animações e breakpoints ao Design System existente.

## Evitar

- preservar a identidade visual original sem adaptação;
- sobrecarregar a página com efeitos;
- usar seções completas quando um componente simples resolver;
- adicionar dependências sem necessidade.
