# Componentry — Guia de uso

Fonte: https://componentry.dev

## Papel dentro da Skill

Utilizar como camada de interação e microanimações sofisticadas.

## Priorizar para

- componentes React animados;
- microinterações;
- efeitos de entrada;
- efeitos de scroll;
- interações sofisticadas;
- componentes experimentais;
- animações modernas;
- elementos visuais diferenciados.

## Contexto preferencial

Dar preferência quando o projeto utiliza React, Tailwind CSS e shadcn/ui.

## Critério de seleção

Usar somente quando a interação melhora feedback, hierarquia, orientação ou percepção de qualidade.

## Evitar

- transformar toda a interface em uma demonstração de animações;
- adicionar dependências pesadas para efeitos simples;
- comprometer acessibilidade ou desempenho.

## Adaptação

Normalizar duração, easing, hover, focus, cores, spacing e comportamento responsivo para o Design System existente.
