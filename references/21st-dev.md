# 21st.dev — Guia de uso

Fonte: https://21st.dev

## Papel dentro da Skill

Utilizar como grande biblioteca para pesquisa e comparação de componentes e blocos React.

## Priorizar para

- dashboards;
- sidebar;
- navbar;
- Hero;
- Pricing;
- Footer;
- autenticação;
- formulários;
- tabelas;
- filtros;
- cards;
- modais;
- command palettes;
- configurações;
- páginas administrativas;
- componentes SaaS;
- blocos de marketing.

## Regra de comparação

Quando houver múltiplas alternativas, comparar UX, acessibilidade, responsividade, dependências, complexidade, manutenção e compatibilidade antes de escolher.

## Critério de seleção

Priorizar componentes acessíveis, responsivos, reutilizáveis, visualmente consistentes e fáceis de integrar.

## Adaptação

Não copiar a aparência original automaticamente. Normalizar o componente para o Design System e a stack existentes.
