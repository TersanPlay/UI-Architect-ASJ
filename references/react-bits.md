# React Bits — Guia de uso

Fonte: https://reactbits.dev

## Papel dentro da Skill

Utilizar como camada de acabamento visual e movimento.

## Priorizar para

- backgrounds animados;
- textos animados;
- hover states sofisticados;
- microinterações;
- cards interativos;
- cursores;
- transições;
- elementos decorativos;
- Hero Sections;
- efeitos visuais de landing pages.

## Critério de seleção

Antes de usar um efeito, verificar se ele melhora compreensão, feedback, hierarquia, continuidade ou percepção de qualidade.

## Evitar

- animações decorativas em excesso;
- múltiplos efeitos simultâneos;
- componentes que aumentem desnecessariamente o bundle;
- efeitos que prejudiquem legibilidade;
- animações que ignorem `prefers-reduced-motion`.

## Adaptação

Normalizar cores, tipografia, spacing, radius, velocidade, easing, hover e focus para o Design System do projeto.
