# Exemplo — Sistema administrativo

## Pedido

Criar ou refatorar uma interface administrativa complexa.

## 1. Entender

Mapear módulos, perfis de acesso, tarefas frequentes, hierarquia de navegação, volume de dados, filtros e operações críticas.

## 2. UX

Priorizar Refero para estudar padrões maduros de:

- administração;
- navegação lateral;
- gerenciamento de usuários;
- permissões;
- configurações;
- tabelas;
- filtros;
- busca;
- formulários;
- modais;
- empty states;
- notificações.

## 3. Componentes

Usar 21st.dev para comparar implementações de sidebar, data table, filters, forms, dialogs, command palettes e configurações.

## 4. Regra de composição

Evitar excesso de cards e efeitos. Interfaces administrativas devem priorizar clareza, densidade adequada, previsibilidade e velocidade operacional.

## 5. Refatoração

Classificar a interface atual em:

- Manter;
- Melhorar;
- Substituir;
- Adicionar.

Preservar funcionalidades existentes salvo instrução explícita em contrário.

## 6. Validação

Validar responsividade, teclado, contraste, foco, permissões visuais, ações destrutivas, loading, empty, error, tabelas largas, formulários longos e estados disabled.
