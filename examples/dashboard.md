# Exemplo — Dashboard administrativo

## Pedido

Criar um dashboard administrativo para gerenciamento de usuários.

## 1. Entender

Identificar perfis de usuário, ações principais, volume de dados, filtros necessários, permissões e Design System existente.

## 2. Referência UX

Consultar Refero para estudar como produtos maduros organizam:

- gerenciamento de usuários;
- filtros;
- busca;
- bulk actions;
- permissões;
- navegação administrativa;
- estados vazios e erros.

## 3. Componentes

Pesquisar no 21st.dev alternativas para:

- sidebar;
- data table;
- search;
- filters;
- dropdowns;
- pagination;
- dialogs;
- command menu.

## 4. Movimento

Consultar React Bits ou Componentry somente para microinterações que melhorem feedback ou hierarquia.

## 5. Implementação

Adaptar tudo à stack existente. Na ausência de stack definida, usar React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Radix UI + Lucide Icons.

## 6. Validação

Validar desktop, tablet e mobile, navegação por teclado, overflow da tabela, loading, empty, error, hover, focus, selected e disabled.
