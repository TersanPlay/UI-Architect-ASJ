# Exemplo — Landing page SaaS

## Pedido

Criar uma landing page moderna para uma aplicação SaaS.

## 1. Entender

Definir proposta de valor, público, ação principal, prova social, conteúdo real, stack e Design System.

## 2. Estrutura

Pesquisar primeiro no Aceternity UI por estruturas adequadas para:

- Hero;
- Features;
- Product Showcase;
- Testimonials;
- Pricing;
- CTA.

## 3. Alternativas

Pesquisar no 21st.dev alternativas de Hero, Pricing, Footer e blocos de marketing.

## 4. Acabamento

Usar React Bits para backgrounds, efeitos de headline ou interações sutis somente quando melhorarem hierarquia ou percepção de qualidade.

Usar Componentry apenas quando uma microinteração mais sofisticada for realmente justificável.

## 5. UX

Consultar Refero quando houver decisões de navegação, conversão, onboarding ou apresentação do produto que se beneficiem de padrões consolidados.

## 6. Adaptação

Normalizar todos os componentes para a mesma tipografia, paleta, spacing, radius, containers, iconografia, hover, focus e motion.

## 7. Validação

Verificar legibilidade, CTA principal, responsividade, contraste, performance, reduced motion e comportamento em conteúdo real.
