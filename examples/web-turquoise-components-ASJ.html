01 · component composition

Motion e estrutura com função clara.

O Bento Grid e o Spotlight seguem a lógica de composição do Aceternity; cards reagem ao cursor e entram em cena com um tratamento inspirado no React Bits. A geometria, paleta e tipografia são normalizadas pelo Design System da página.

Aceternity UI + React Bits
Aceternity · Bento Grid

Composição assimétrica sem perder leitura.

Uma área maior recebe a mensagem principal e uma visualização forte, enquanto os módulos adjacentes sustentam contexto e detalhes sem competir pelo mesmo peso visual.

React Bits · Spotlight Card

Feedback local sob o ponteiro.

O brilho aparece somente na área relevante do card e desaparece quando não ajuda a interação. O dourado permanece restrito ao detalhe premium.

React Bits · Motion

Movimento contido.

Uma única composição animada demonstra profundidade sem transformar a interface em uma vitrine de efeitos.

Aceternity · Section Pattern

Uma seção completa pode nascer de blocos diferentes e ainda parecer uma única decisão de design.

Estrutura, contraste, bordas, espaçamento e motion são tratados como tokens compartilhados. A origem do componente deixa de ditar a aparência final.

03 · interaction layer

Interações sofisticadas, sem ruído.

Inspirada no Componentry, esta área usa cards empilhados durante o scroll e um dock magnético. O objetivo é demonstrar percepção de profundidade e feedback, mantendo a interação subordinada à tarefa.

Componentry · Magnetic Dock
Componentry · Sticky Scroll Cards

Profundidade progressiva

Os cards permanecem legíveis enquanto a pilha cria profundidade. Em telas menores o comportamento sticky é removido para preservar previsibilidade.

Microinteraction

Forma acompanha intenção

O card intermediário introduz um detalhe dourado mais raro, reservado para sinalizar valor premium ou ação especial.

Motion discipline

Reduzir antes de adicionar

Quando a animação não melhora feedback, orientação, hierarquia ou percepção de qualidade, ela deve ser removida.

Componentes diferentes. Uma linguagem só.

O objetivo do UI Architect ASJ não é provar quantas bibliotecas cabem numa página. É selecionar o mínimo necessário, normalizar tudo e entregar uma experiência que pareça projetada de ponta a ponta.
